# 登录问题

报错
如果提示页面证书不合法，关闭WiFi使用手机数据。
登录时提示SSO单点调用获取用户信息失败
二级账管首先用工号在系统内查此工号对应的手机号是否是登录运营商app的手机号，如果不是修改成登录运营商app的手机号，系统内手机号需唯一。
并且需要用姓名查是否只有一条数据，如果查出来一个姓名有两条数据，需要把非cbss的工号锁定。
并且把非cbss的工号的手机号码换成一个非登录运营商app的手机号。需注意，登录运营商app的手机号对应绑定的cbss工号必须一致。
需注意，登录运营商app的手机号  对应绑定 的cbss工号必须一致 。
如果都没有问题可以让提出人清理app缓存 重新验证。
找不到终端智能管理菜单
需找各地市工号负责人进行菜单赋权。
登录后权限是空白的
需找二级账管修改角色对应的标签是营业员/智家。
