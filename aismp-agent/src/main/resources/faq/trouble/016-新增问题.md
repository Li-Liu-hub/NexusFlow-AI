# 新增问题

营业拆机工单与回收明细提示：固网终端报竣对端系统返回respCode：9999,respdesc:业务校验不通过：工号[jl-quy1]未查询到员工信息。
需要二级账管到系统管理>用户管理下根据工号[jl-quy1]进行查询，确定查询不到工号信息，需要新增一个用户，手机号码需要与登录运营商公众APP的手机号码保持一致。
需要营业员用新建的账号登录运营商公众APP进行回收。
固网终端报竣拆机单未查询到串码信息,不再进行终端报竣,等待定时扫表后重新调用查询接口。
需先回收终端再办理拆机单，如先拆机，需办理拆机单当日进行回收终端录入。否则回收失败。后续开发补录功能。
营业厅归属地市、区县、仓位为未知
因为系统内没有此营业厅信息导致。需二级账管到系统管理>营业厅管理菜单下，新增一个营业厅。即可对应到地市、区县、仓位。
