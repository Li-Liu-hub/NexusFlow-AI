# 功能问题

终端无法分配
核查终端表数据是否为空是否为空 ，如果为空，可让二级账管在 终端信息维护-终端维护 补全终端信息。
已入库的设备怎么进入到其他库
通过建调拨单形式进行调拨
备注：如果使用的是批量调拨，导入终端是批量调拨 确认入库也是批量入库确认，菜单需一致。
终端在智家手里但是智家库内没有该终端信息
四级库管核查库内没有该终端，如果有将终端分配给智家领用。
如果没有，需找二级账管进行新建0元入库单，入库后下发给四级库再进行备机派发。
终端在另一个智家手里如何分配给要安装的智家
四级库管可在（PC端 领用管理-终端领用）将终端释放成可用，然后再分配。
四级库管派备机系统显示待智家领用确认，智家APP终端领用里没设备
首先确认这个终端下发给的智家工号是不是cbss工号且 （cbss工号需在用工号）
如果不是 cbss工号，需要智家找四级库管先把智家备机都收回来然后找二级账管把不是cbss工号的这个账号锁定，然后二级账管新建一个cbss工号  然后再找四级库管下发设备。
如果是cbss在用工号 需要确认智家工号是不是和统一运营绑定的工号是且是唯一一个。
如果有两个需要去找统一运营工作人员解除不是在用cbss工号的绑定关系。
如果是再用的cbss工号 ，需要看系统内是不是俩工号，并且手机号码不一致 ， 需要确认cbss工号 绑定的手机号是不是登录运营商app的手机号，如果不是，把cbss工号对应的手机号换成登录运营商app的手机号。
掌上运维报错
调用固网终端接口返回：资源验证失败。操作人和终端仓位不一致。
需要核查终端领用人是否是此人，如果一致并且也是cbss的再用工号，用系统内领用人的cbss工号去统一运营核查是否与统一运营没有绑定关系或者统一运营有两条绑定关系。需保留当前APP使用的一条。
提示业务校验失败：串码已占用
终端设备的领用人和实际安装的领用人不一致 ，需要智家找四级库管收回设备，然后派发安装人。
提示获取渠道返回空
需要核查要安装的终端是否在库内有信息，如果终端在库内没有信息，但是设备在智家手里，让智家找二级账管新建0元单将设备入库再下发。
二级库管操作界面
设备已经安装但是手里的设备还是显示备机
需要确认智家施工完毕后，回填工单的串码与安装串码是否一致，CB工单是否竣工。
需要确认业务号码安装了几个终端（管智家要业务号码绑定的终端串码）在终端信息查询核查终端是否都是领用状态并且都是该智家领用的。
如果有没有领的需要让智家找二级库管下发。
如果是一个设备并且已经领用备机了，需要确认cbss工号在统一运营是否有绑定关系并且只有一条。
