# 库存管理

采购入库管理（二级账管权限）
商城采购入库：（T-1）同步供应链审批完成的订单至终端智能管理系统，采购入库列表。账管员可根据采购物资到货情况采购入库。如物资分批到货先进行拆单，再导入串码入库。如果采购单与实际情况不符也可选择拒绝入库。
0元入库单：新建0元入库单，根据采购类型划分：0元新机入库、旧机入库、代维入库。创建后跳转到商城采购入库菜单，导入串码进行入库，入库后在终端查询处有入库类型标识。
库存调拨（省级终端主管审核跨本地网调拨权限，账管建调拨单权限，库管出库、入库权限）
调拨类型分为：调拨、下发、回收、回退。（下发，调拨的限制终端状态是可用状态；回收，回退的限制终端状态为可用、待报废、待检。）
调拨方式分为：
单一物料型号调拨。对应操作菜单-库存调拨。
批量调拨：两仓位间可一次调拨多种物料型号的终端。对应操作菜单-批量调拨。
导入式批量调拨：两仓位之间可通过导入调拨明细形式进行多物料型号调拨。对应操作菜单-导入式批量调拨
四级库调拨：四级库间调拨无需上级审批。可进行单一物料调拨和批量调拨。对应操作菜单-四级库调拨、四级库批量调拨
跨本地网调拨：地市间终端调拨。对应菜单-跨本地网调拨
批量调拨流程：
账管员创建调拨单：库存调拨/批量调拨/导入式批量调拨/跨本地网调拨菜单>新建调拨单。
调出方库管出库： 库存调拨/批量调拨/导入式批量调拨/跨本地网调拨菜单>导入终端出库。
调入方库管：入库确认>批量入库确认>跨本地网调拨入库确认>确认入库。注意：调拨发起方使用什么菜单新建的调拨单，那入库确认也需要到相同的菜单下进行入库确认。
跨本地网调拨：账管员创建调拨单>省级终端主管审批>出库方库管出库>入库方库管入库，仅支持单一物料类型调拨。
四级库间相互调拨：四级库A与四级库B同属一个三级库/二级库管理，可互相调拨，无需审批。
