# 终端信息维护（二级账管权限）

终端改串码
录错串码或故障返厂后终端无法维修返回新终端时可进行串码终端替换。修改串码旧串码不限制位数、新串码需12位标准串码。二级账管可修改本级及下级仓位。
终端改串码日志
可查询改串码的操作人员、操作时间、修改前串码、修改后串码，做到串码修改可查，可溯。
终端维护
可单独或批量维护终端信息、包括终端状态、终端分类信息。权限如下：
占用改待检（2级账管权限）
备机改占用（2级账管权限）
待检改可用、待报废、故障返厂（2、3、4级账管权限）
待回收改待检（回收对应仓位）
可用改待检（2、3、4级账管权限）
特殊限制：
批量备机改占用时需填写用户号码、业务类型、领用人工号、领用人姓名，并校验。
批量修改终端状态待回收改待检/占用改待回收时，需校验终端大类是否具备，如果串码在系统内缺少终端大类需要在修改模板中补充物料编码再进行状态修改维护。维护成功后系统自动补充好终端四级分类。
终端报废功能限制只允许待报废改报废。
营业装维的待回收只允许库管修改为待检
回收菜单中待检允许改可用、待报废、故障返厂
