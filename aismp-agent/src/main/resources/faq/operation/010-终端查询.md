# 终端查询

终端信息查询
可单个/批量查询，查询出本库位及下级库位终端信息，点击终端详情可查看终端全生命周期数据。
客户号码：终端装机时回单填写的客户号码，包含宽带号码、IPTV号码。只做记录，不做校验，以智家填写为准。
操作日期：在系统内操作终端进行状态变更的时间范围。
入库类型：新终端：采购入库0元新机入库；利旧终端：使用次数大于等于1次的。
业务类型：移/换机 装机(IOM传的数据)、修障(公客传的数据)。
采购类型：采购入库、0元新机入库、0元旧机入库、代维入库。
二次入库时间为四级库回收统计处，确认收货时间。终端维护处，待回收转待检、占用转待检时间。
本库位库存包括以下状态：可用、待检、待报废、调拨在途、待智家领用确认、备机、领用退回。
调拨日志查询
可查询本级与下级库位的终端系统内操作日志。可配合操作类型进行查询。
串码移动明细查询
可单个/批量查询导出终端全生命周期流程。省级、二级账管、二级库管可查全省范围内终端，其他角色仅能查询本级及下级。
