# 领用管理（四级库管权限）

终端领用
终端经逐级下发/调拨到四级库，四级库管通过领用管理>终端领用菜单将终端单个/批量派发给智家工程师。也可将智家库内终端释放为可用/待检。智家通过终端智能管理APP确认领用后，终端状态变更为备机，且与领用人进行绑定。可在APP内查看库内备机总量，对于备机领用超30日未使用的，为超长备机，需尽快使用出库或退回四级库。库管也可收回超长备机。智家还可在APP内查看到近60内终端的使用情况。
领用退回待处理
如对库管下发的备机有异议可拒绝领用。智家拒绝领用后，终端退回四级库，库管在领用退回待处理菜单进行确认，确认后终端状态变更为可用，方可重新分配。
注意：库管给智家工程师下发备机，智家未领用的终端，状态为：“待智家领用确认”，智家是无法使用的。智家拒绝领用后，四级库管在领用退回待处理菜单未处理的，状态为：“领用退回待处理”，库管无法将终端再次分配。
