# 报表管理

终端进出库统计表
权限只给到省管理员和二级账管、库管。
根据登录工号展示报表内容，省看全省进出库统计、地市看本地市进出库统计。
按仓位、终端大类、时间进行筛选，其中时间默认查询本月（1号到查询日期前一日）数据按日更新。
期初在库数量汇总统计状态包括：待检、可用、待报废、备机、调拨在途、待智家领用确认、领用退回。
本期采购入库数量汇总包含正常采购入库和通过0元入库单入库的数量。
本期调配入库：统计的是跨本地网调拨的入库数量。
本期回收旧终端入库数量：统计的是待检转可用/转待报废数量。
本期回收旧终端待检数量：统计的是待回收转待检/占用转待检数量。此部分数量包含了本期回收旧终端入库的数量。
本期入库数量汇总=本期回收旧终端待检数量+本期维修返回终端入库数量。
本年统计通本期口径一致，时间纬度为年统计。
终端进出库统明细表：在统计表基础上增加终端四级分类。其余数据统计口径不变。
终端库龄预警通报表
选项：终端状态：可用、备机；时间：按月查询，默认查询本月（1号到查询日期前一日）数据按日更新。
新终端：采购入库、0元新机入库。
利旧终端：回收统计-库管确认收货后，转可用的终端；终端维护处账管转可用的终端；0元入库处-入库类型为0元旧机入库终端。
库龄时长：新终端按首次入库时间开始计算；利旧终端按最后一次翻新利旧入库，更改状态为“可用”开始计算。
终端备机统计表：
查询条件：时间按月查询，默认查询本月（1号到查询日期前一日）数据按日更新。
分角色查询备机汇总数据，当勾选查询范围为查询选中仓位级下级仓位时，可看各仓位备机明细数据。
备机领用时长按领用时间开始计算。
每日终端状态稽核表
查询条件：时间：T-1，按日和时间段查，默认展示前一天数据，时间为订单生成时间。
目标状态：应该变更的终端状态。
实际状态：实际终端变更的状态。
原因：工单返回的报文，可通过此提示分析目标状态与实际状态不一致的原因。
智家回收统计表
查询条件：时间按月查询，默认查询本月（1号到查询日期前一日）数据按日更新。
应回收终端：取装维调用拆机数量，公客传的拆机明细。
实际回收终端：智家扫码回收并成功报竣的数量。
扫其中无法识别终端数量：回收时选择串码无法识别的。串码是9个8的数量。
智家回收工单明细
查询条件：T-1按时间段查询，默认查询全部智家回收数据。
回收时间：报竣成功时间。
此表仅展示智家回收报竣成功的数据。
营业回收统计
查询条件：按月查询，默认查询当月1日-查询日期前一天数据。
拆机应回收：IOM传的拆机明细。
拆机实际回收：营业回收录入，报竣成功，占用转待回收数量。
营业拆机工单与回收明细表
查询时间：按时间段查询，如果查到当天，数据结果为开始时间到查询日期前一天。
拆机应收数量：IOM传过来的数量。
拆机实际回收数量：营业扫码回收并成功报竣的数量。
回收终端串码明细：营业回收录入的，已回收的串码。实际回收为“0”的则无终端串码。实际回收为“1”但是却没有串码的，需结合后面的其他原因，审核免赔、终端赔付的不展示终端串码。或报竣失败的报文提示。
新增非标终端串码自动生成能力：针对无法识别串码终端实现 12 位规则化自动编号（2 位地市 + 6 位年月 + 4 位序号），同步记录至回收台账，支撑异常终端全流程可管可溯。
拆机时间：营业员办理拆机工单时间。
实际回收时间：回收终端报竣时间。
实际回收人：先取固网终端人员信息，如办理拆机单的营业员工号系统内没有，则取CB人员信息。实际回收时会报竣失败，实际回收数量为“0”，其他信息列会提示报竣失败报文。固网终端报竣对端系统返回respCode:9999,respdesc:业务校验不通过，工号[vjlf1001903]未查询到员工信息。
业务号码：取CB工单拆机单上的业务号码。
终端库存统计表
查询时间：按月查询，默认查询本月1日-查询日期凌晨4点的数据。
查询范围查询选中仓位：展示选中仓位及下级仓位的库存统计数据。
查询选中仓位及下级仓位：展示选中仓位及下级仓位的各个库位库存明细数据。
周转周期：库存周期=截止到查询日期前一天的库存数量(可用、调拨在途、备机、待智家领用确认、智家领用拒绝)/周使用量。如4月份的周使用量=（1、2、3月的使用量总量/天数）*7。每月周使用量为固定值。
可用统计状态包括可用、在途，待智家领用确认、智家拒绝领用/领用退回待处理。
备机统计状态包括备机。
终端翻新利旧统计
查询条件：按月查询，默认查询当月1号到查询日期当天凌晨四点。数据口径：
回收数量：四级库回收数量为回收统计处确认收货，虚拟五级库待回收转待检数量。
翻新数量：待检转可用；
利旧数量：备机转占用；
利旧使用＜30天：占用＜30天；
终端返修统计
查询条件：按月查询，默认查询当月1日-查询当日凌晨4点。
返修率：分母：按月累计保修期内采购中终端数量；分子：返修终端数量；保修期：光猫、机顶盒、FTTR、FTTO保修期27个月；路由器、摄像头保修期24个月。
已修复终端数量：包含以旧换新（关联返厂工单）修复，串码替换的；返返回处理中转可用的终端数量。
返修终端数量：包含在途终端数量。
