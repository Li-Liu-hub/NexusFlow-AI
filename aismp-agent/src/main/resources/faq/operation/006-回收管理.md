# 回收管理

营业回收
营业员在办理拆机/清退预存款业务前，需先到终端智能管理系统回收终端，如当时未现回收终端，需要在办理CB拆机业务当天24:00前完成回收录入，否则系统无法统计到回收终端。
营业员登录运营商公众APP，找到终端智能管理菜单，点击进入。
点击扫码回收，填写宽带号码/IPTV号码，在对应的号码下添加回收设备。
扫描/手输终端SN码，固网终端查询库内是否有此终端，有直接返回给营业员此终端信息，没有返回终端分类为未知，需补充终端大类、小类、厂商后再添加。
如遇无法识别终端串码，点击无法识别按钮，点击后营业员需补充终端大类、小类、厂商，系统将按照2位地市+6位年月+4位串码格式自动生成12位标准串码。
如遇终端赔付：点击终端赔付，在终端对应的配件下选择是否赔付，补充终端大类、小类后进行添加。
如遇拒绝赔付且未携带终端：点击审核免赔，填写OA工单和终端大类、小类，信息进行回收。
支持一个号码同时录入多个终端，录入添加后统一点击提交，信息提交至固网终端。回收终端数量可在当日/当月回收终端量中进行查询。
回收终端后营业员办理CB拆机单，办理后终端状态将自动从占用转为待回收。办理拆机单与回收终端需同天进行，如隔天录入，终端状态无法自动进行变更。
营业员如发现自己办理的拆机单录错了终端串码可在APP中点击当日回收终端量，找到错误串码进行修改。
如有押金清退用户到厅归还终端，营业员需点击押金清退按钮进行回收终端。
智家回收
在MOS系统中进行扫码回收
回收统计（有回收终端权限的库位有权限操作）
营业、智家回收成功的终端，即报竣成功，状态变更为待回收状态的终端将展示在回收统计列表中，四级库管先进行确认收货(确认收货后，终端状态由待回收转为待检)，再根据质检结果进行打标，可打标为可用、故障返厂。注意：确认收货时间，为二次入库时间，转故障返厂将送回厂家进行维修。
旧机入库：智家、营业扫码录入终端属于库内没有的终端，需补充终端大类小类厂商型号物料名称等信息，选择入库库位后进行确认收货，之后转可用、故障返厂。
四级库管在回收统计做二次入库/旧机入库时，如发现营业。智家回收时录错串码，可先进行串码修改再进行入库。回收类报表数据将同步修改。
回收时改串码将校验串码归属地市、状态，修改为非本地市、非占用状态终端时将提示错误，无法进行修改。修改成功后，原错误串码将回退到原库位、原状态。
回收管理只有四级库管有操作权限，其他角色可查询。
回收业务号码：回收时营业员/智家录入的业务号码。回收时间：拆机的终端报竣时间。
