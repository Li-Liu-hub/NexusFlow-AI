# 系统管理（省级终端主管、二级账管权限）

参数配置
用户管理：维护用户信息，锁定账号前需现将终端退回至上级库，同一个用户系统内不可存在两个在用工号。绑定电话号应唯一。营业、智家系统内使用工号需与统一运营绑定工号一致。
仓位管理：维护仓位信息。有仓位变更时需先将终端退回至上级库。
新增营业厅管理，有新增营业厅的需在系统中同步新增，否则回收信息将无法获取。
属性管理-仅省分主管有权限：管理厂家、终端类型、型号、物料等。
