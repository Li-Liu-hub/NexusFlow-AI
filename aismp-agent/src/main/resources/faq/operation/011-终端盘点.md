# 终端盘点

盘点单创建
省级终端主管在终端信息盘点菜单：创建盘点单。在实盘信息查询菜单：查询库存盘点完成情况。
四级库盘点
四级库管根据盘点通知，填写盘点状态终端串码，填写串码会自动与系统生成的盘点信息比对，如少填系统会提示有串码未填写是否提交，如填写了非系统生成的盘点串码，需符合盘点单要求的盘点状态。
非库内终端无法添加至盘点单，需先进行旧机入库。填写完毕后进行提交。提交后四级账管进行盘点单查看，对于存在盘点差异处进行差异原因填写。四级库管账管填完单子展示在三级账管的盘点信息查询中，展示在二级账管的盘点审核中，实盘信息查询中。二级账管盘点审核处查询是否盘完时为盘完，二级账管盘点审核提交后，省级终端主管看这个盘点单算盘完，未提交为未盘完。
虚拟三级库盘点
库管填完账管填，填完单子展示在二级账管的盘点审核中，二级账管盘点审核处查询是否盘完时为盘完，二级账管盘点审核提交后，省级终端主管那看这个盘点单算盘完，未提交为未盘完。
三级库盘点
三级库管可输入或导入盘点单数量进行盘点。库管填完账管填差异，填完单子展示在二级账管的盘点审核处。二级账管盘点审核处查询是否盘完时为盘完，二级账管盘点审核提交后，省级终端主管那看这个盘点单算盘完，未提交为未盘完。
二级库盘点
二级库管可输入或导入盘点数量进行盘点。库管填完账管填差异，填完单子展示在二级账管的盘点审核处。二级账管盘点审核处查询是否盘完时为盘完，二级账管盘点审核提交后，省级终端主管那看这个盘点单算盘完，未提交为未盘完。
盘点审核、实盘信息查询
所以盘点单汇总到二级账管盘点审核处进行统一提交。提交后省级终端主管可在实盘信息查询进行查看。二级账管可在实盘信息查询菜单查看本级及下级生成的所有盘点单，包括往月数据。
盘点差异串码明细表：同一库位盘点以最后一次盘点结果为准。数据更新时间为每日凌晨4点更新上一天的盘点差异数据，盘点差异需盘点完成后第二天进行查看。差异串码中剔除了已占用的数据。
库存盘点月度报表：同一库位同一盘点状态盘点多次的以最后一次盘点结果为准进行统计。
