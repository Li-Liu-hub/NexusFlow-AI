# 角色职责

终端主管
负责二级仓位和操作人员新增和维护；跨区域终端调拨审核；基础数据（厂商、型号、物料等数据的新增、变更）操作，下发、查看库存盘点单。
二级仓位账管员
负责终端调拨单的创建，包含调拨、下发、回收、回退。负责跨本地网调拨单的创建。终端信息维护，包含修改终端串码、终端维护等，三四级仓位、营业厅和操作人员新增和维护，本仓位及下级仓位的盘点审核、实盘信息查询、盘点单的填写与提交。终端报废管理。
二级仓位库管员
负责终端调拨单出库、入库。负责跨本地网调拨单的终端出入库。盘点单填写。终端故障返厂管理。
三级仓位账管员
负责终端调拨单创建,下级仓位终端的调拨、下发、回收，以及对上级仓位的终端回退。
三级仓位库管员
负责终端调拨单出库入库。终端故障返厂管理
四级仓位账管员
负责终端调拨单的创建，对上级仓位的终端回退。
四级仓位库管员
负责终端调拨单出库、智家工程师的备机发放及回收。拆机终端二次入库/旧机入库。终端故障返厂管理。
终端运营角色
提供报表分析统计查询能力。
