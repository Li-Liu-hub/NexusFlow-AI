# 引言

原固网终端管理全流程涉及SAP、3GESS、POS三个系统，且系统间两两关联，频繁出现卡单现象，数据不同步导致终端状态不一致，系统间不能进行数据校验恢复。且系统功能老旧，且优化不足，功能点缺失，无法满足固网终端管理需求，因此搭建了新的固网终端管理系统。新系统整合各系统功能，提供统一的终端管理平台。管理贯穿固网终端采购入库、调拨、领用、出库、回收、利旧、报废等各个环节，实现终端串码级全生命周期管理；通过与供应链系统、cbss系统、IOM、公客等系统的交互实现固网终端的数据贯通和自动化工单驱动，实现终端闭环管理，通过终端数据统计、分析、展示、预警等功能，实现管理人员及时掌控终端的库存、使用等情况，提高管理效率和科学性。
